Crowd Control Field Manual

Standard operating procedures during peak Sandhi Puja and Aarti surges.

How is Estimated Waiting Time calculated? +

Our empirical algorithm weights each queued devotee: General × 2.0 min-factor, VIP × 1.0 fast-track factor, cleared in batches of 5 — i.e. Math.ceil(((GeneralCount * 2.0) + (VipCount * 1.0)) / 5) minutes. It recomputes on every add / admit.

What happens if the array memory resets during shift change? +

The application automatically mirrors the JavaScript array in browser localStorage. Even if a volunteer accidentally refreshes the browser, zero queue data is lost.

How do volunteers cooperate using Git and GitHub? +

The team works using feature branches (e.g. feature/queue-logic, feature/3d-styling), reviews Pull Requests, and auto-deploys via GitHub Pages or Vercel.
